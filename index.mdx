GeckoLib is an animation and rendering engine for Minecraft mods. It lets you attach Blockbench-authored 3D animations to entities, block entities, items, and armor — with support for concurrent animation controllers, sound and particle keyframe events, server-triggered animations, and procedural math expressions via MoLang.

## Supported modloaders

GeckoLib 5 ships separate artifacts for every major Minecraft modloader. The core API is identical across all three — only the Gradle dependency changes.

<CardGroup cols={3}>
  <Card title="Forge" icon="fire" href="/installation">
    `geckolib-forge-<version>`
  </Card>
  <Card title="Fabric" icon="th" href="/installation">
    `geckolib-fabric-<version>`
  </Card>
  <Card title="NeoForge" icon="bolt" href="/installation">
    `geckolib-neoforge-<version>`
  </Card>
</CardGroup>

<Note>
  GeckoLib uses [Blockbench](https://www.blockbench.net/) as its authoring tool. Create your model and animations in Blockbench, export the `.geo.json` and `.animation.json` files, and reference them from your GeoModel class.
</Note>
